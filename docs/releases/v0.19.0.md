# Starboard v0.19.0

Released 15 November 2026.

## Added

- **Download without a VPN.** Both set-ups now ask how your downloads connect: with your VPN account (recommended) or without one. Going without one shows a plain warning first, with Cancel as the default, and Settings, Downloads, VPN adds or removes a VPN later.
- **Automatic updates for everything.** Settings, Updates lets each part update by itself: Starboard, Reelix, your other apps, Starboard's plug-ins and Jellyfin's plug-ins. Each stays deactivated until you activate it. Updates happen once a day in the hours you choose, one at a time, each with a copy first, a check afterwards and the way back by itself.
- **One place for updates.** Settings, Updates lists everything that can be updated, with Update now on each, the same password and progress for every part, and Recent updates. An alert tells you when an update is waiting for you.
- **Copy issues for an AI helper.** Activity, Downloads, Queue has Copy issues for an AI helper and Download as Markdown: every download that needs attention, with what Starboard knows and already tried, ready to paste into an AI helper. Keys, passwords and private addresses are taken out. Starboard's API 1.3.0 gives the same.
- **Plug-ins from a zip file.** A private plug-in with no address, such as On demand, can be added with Upload a zip file in the Catalogue. Starboard checks the zip, shows what the plug-in may do, then builds and installs it step by step, with limits. Its page has Update from a zip file.
- **Library clean-up and Jellyfin libraries.** A plug-in such as Library clean-up can move films and series into a holding folder in your media folder and put them back with Put back on each row, never deleting. A plug-in such as On demand can have Starboard add its libraries to Jellyfin. Each needs a permission you approve, said plainly first.
- **Jellyfin's pictures outside its settings folder.** New installs keep Jellyfin's posters and details in their own folder, so Jellyfin watches far fewer folders. Settings, Jellyfin, Pictures and details moves an older install the same way.
- **Plug-in API 1.15.** For plug-in makers: containers built from a zip file, Jellyfin libraries, the holding folder in the media folder, Put back on a custom screen's rows, and a card title for each card size. Plug-ins made for earlier versions work as before.
- **Help for every plug-in.** The help centre's Plug-ins area has the same eight pages for each plug-in in the collection, from what it does to fixing problems.

## Changed

- **Every dashboard card has the band.** Every built-in card now has the grey band plug-in cards have: a logo, its name, and a status chip and when it updated where it has something to say. A card about one app shows that app's logo. Go through them sits in the Still to set up card's band, and a small card's chip shows only its icon.
- **A new install gets the newest release.** Run first and the installer install the newest release instead of the main branch. For testing, --main keeps the main branch.
- **Help, simplest first.** The set-up help starts with the default install, with more apps and advanced options apart.
- **Reelix you can name.** Starboard notes the exact Reelix build it installed, such as lite-0.8.7-trex.2.

## Fixed

- **The Docker helper image.** Starboard downloads its Docker helper image again when it is missing, so activating a plug-in no longer fails with No such image.
- **Plug-in buttons that ask first.** A plug-in button with a question, such as Line speed's Test now, now asks it, starting on Cancel.
- **Plug-in list settings.** A list setting is a box with one value a line, and saves.
- **Removing an app plug-in.** Its entry on Apps goes with it, and Settings, Tdarr says Tdarr is not installed.

## Security

- **Plug-ins from a zip are built with limits.** Only a zip can install a plug-in built on your computer. Its Dockerfile is checked first, and the build cannot reach your home network, folders, Docker or apps, with limits on memory, processor, time and size.
- **The holding folder only when you approve.** Only a plug-in with the library:holding permission, approved with its high risk said plainly, can reach your whole media folder.
- **Checks.** The unit tests, the browser journeys, the accessibility checks (axe, reading order, keyboard tasks and the layout check), the API contract tests and example plug-ins, the end-to-end update test, the help check, the private details check and the security scans ran on this release.

## Your settings and the way back

Nothing changes in your settings: every automatic update stays deactivated until you activate it, and an install with a VPN keeps it. To go back, run ./update.sh --to v0.18.0.
