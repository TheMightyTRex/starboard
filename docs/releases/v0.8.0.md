# Starboard v0.8.0

Released 5 November 2026.

## Added

- **Set up in the terminal.** ./install.sh --terminal asks every set-up question in the terminal, for a server with no desktop and no other device: your password, the apps for your media server and download hours, with Back, help and a plain mode for screen readers. Help: [Set up Starboard in the terminal, with no browser](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/set-up-in-the-terminal.md).
- **Drive pools.** A new Pool tab on System, Storage adds drives to one pool, balances the files, takes a drive out, and makes a drive a backup, with a check of every change before it is made. Help: [Add a drive to the pool](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/add-a-drive-to-the-pool.md) and [What a drive pool is](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/basics/what-is-a-drive-pool.md).
- **Feedback from the terminal.** Press f at any question to report a problem with that step, and send it as a QR code to scan with your phone, as a link, or as a file. Help: [Set up Starboard in the terminal, with no browser](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/set-up-in-the-terminal.md#send-feedback-from-the-terminal).
- **What is new in Reelix.** Apps, Updates shows the changes in a waiting Reelix update, from Reelix's own changelog, and says when Reelix has been updated. Help: [Update your apps](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/update-your-apps.md#what-is-new-in-reelix).
- **A guide from a bare computer.** Help, Get Starboard up and running: from installing Linux to Docker, then a path for the browser and one for the terminal only, with prompts to ask an AI assistant for help. Help: [Get Starboard up and running, from a bare computer](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/guides/get-up-and-running.md) and [Ask an AI assistant to help you set up](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/ask-an-ai-for-help.md).

## Changed

- **The terminal fits the window.** The heading, the progress bar and the menu stay in place while the step scrolls between them, and the QR code holds more of a report in a larger window.

## Security

- **The pool helper.** Drive pools need a small helper that runs as root, installed only if you say yes to it. Starboard can only ask it for a fixed set of jobs, each checked first, with your password again, and erasing a drive needs the end of its serial number.
- **Feedback reports.** A report never holds your answers to the set-up, passwords, VPN details or the setup code. Answers you type are kept only as keyed fingerprints for this run, and passwords are not kept at all.
- **Checks.** Trivy, OWASP ZAP (signed out, and an active scan signed in), Gitleaks, Bandit, ShellCheck, Hadolint and CodeQL ran on this release. One download address is now also checked to be https; ZAP's one signed-in warning was a false alarm, explained in docs/SECURITY-AND-TESTS.md.

## Your settings and the way back

Nothing to choose. To use drive pools, run ./install.sh again and say yes to the pool helper (it asks for your password, for sudo). To go back, run ./update.sh --to v0.7.7.
