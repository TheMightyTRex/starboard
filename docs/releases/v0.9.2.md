# Starboard v0.9.2

Released 5 November 2026.

## Added

- **Releases.** Settings, Updates, Releases shows every version in its own section, newest first: the one you have is open, each shows a count for each type of change, then what was added, changed and fixed, in colour. Help: [Update Starboard](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/update-starboard.md#find-out-whether-an-update-is-out).
- **Restore.** Settings, Updates, Restore puts back a copy of your settings that Starboard saved, or one from a file, and shows the command to go back to the version before. Help: [Restore a saved copy of your settings](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/restore-a-saved-copy.md).
- **Sign out on every Settings page.** A Sign out button now sits beside the title of every Settings page.

## Changed

- **Update settings.** About and updates is now Update settings, one of three pages under Settings, Updates.
- **Help opens the right article.** The Help button at the top of each page opens the help centre article for that page, such as Check your disks' health on Disk health.
- **A wide terminal used evenly.** The Run first script and the terminal set-up draw in a column up to 100 characters wide, centred in a wider window, and move it when the window changes size.
- **Progress bars drawn once.** Each job has one bar, updated in place; when a job fails, its bar stays, marked, with the problem and Try again, Show the details or Stop below it. Install apps shows a moving bar and the time taken in the same way.
- **Choosing several answers in the terminal.** Up and Down move, Space ticks or unticks and Enter carries on. Typing a number still works, and plain mode keeps typed numbers.

## Fixed

- **curl installed as a snap.** Docker's installer could not download on Ubuntu when curl was a snap. The Run first script now installs Ubuntu's usual curl beside it and explains the error in plain words. Help: [RF-10](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/run-first-errors.md#rf-10).
- **The quick start without curl.** Ubuntu Desktop does not include curl, so the README and the help give the same command with wget. Help: [Quick start: one command sets up everything](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/guides/quick-start.md).
- **Disk health installs what it needs.** Choosing disk health no longer stops with install smartmontools first: the installer installs it, and finds it in /usr/sbin. Help: [Check your disks' health](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/check-disk-health.md).

## Security

- **Checks.** Trivy, OWASP ZAP (signed out), Gitleaks, Bandit, ShellCheck, Hadolint and CodeQL ran on this release and found nothing to fix. The new Restore page asks for your password before it restores, as on Backup.

## Your settings and the way back

Nothing to choose. To go back, run ./update.sh --to v0.9.1. Restore your settings from a copy on Settings, Updates, Restore.
