# Starboard v0.7.4

Released 3 November 2026.

## Added

- **Help centre.** Help for installing and using Starboard, written for people new to home servers: guides, one topic for each task, and the basics. Help in the footer opens it.
- **Reset a forgotten password.** Run ./reset-password.sh on the server. It signs everyone out and shows a new setup code; your apps and settings stay. Help: [Reset a forgotten password](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/reset-a-forgotten-password.md).
- **Not in Jellyfin yet.** Importing watch history now lists the films and episodes Jellyfin does not have yet, in Settings, Jellyfin. Help: [Import watch history into Jellyfin](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/import-watch-history.md).
- **Note issues.** For testing: activate it in Settings, General to note a problem with any page as you find it.

## Changed

- **Messages.** Confirmations appear as cards in the corner, and a settings page shows Saved at and the time beside the button instead.
- **Words.** Settings are activated and deactivated, and show as active or inactive.

## Fixed

- **Disk health.** The page shows again: a mistake in its script had stopped it since 0.7.0.
- **Restoring old backups.** A backup from before 0.6.0 is brought up to date, and a design that no longer exists goes back to the default instead of stopping the restore. Help: [Back up and restore Starboard's settings](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/back-up-settings.md).
- **Large text on phones.** At 175% the Apps page fits the screen, and an app's status goes under its name when they do not fit side by side.
- **Docker access with the ready-made image.** compose.image.yaml now has the line that lets Starboard use the Docker socket. Add your socket's group number there, as the file explains. Help: [Change what Starboard can access](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/change-what-starboard-can-access.md#if-you-used-the-ready-made-image).

## Security

- **Pillow 13.0.0.** The picture library for white Live TV logos had 58 known problems, 5 of them critical. Logos are now read only as PNG, JPEG, GIF, WebP, BMP or ICO.
- **Smaller image.** The image no longer includes pip, which Starboard does not need to run.
- **Sign-in.** The password is never put in the page address, even if Enter is pressed before the page has loaded.
- **Live TV playlists.** A stream check no longer opens a file: link written in a playlist from the internet.
- **Other sites.** New headers stop other sites loading Starboard's files into their pages. Live TV logos stay open to Jellyfin.
- **Exact addresses.** An address that only starts like one of Starboard's own, such as /api/containers - Copy, is now not found.
- **Checks.** Every release is scanned with Trivy, OWASP ZAP, Gitleaks, Bandit, ShellCheck and Hadolint. What each found is in docs/SECURITY-AND-TESTS.md.

## Your settings and the way back

No settings change. To go back, run ./update.sh --to v0.7.3.
