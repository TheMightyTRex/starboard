# Starboard v0.27.0

Released 22 November 2026.

## Added

- **Filters on Discover's rows.** Above the rows, choose In your library or Not in your library, a decade, Released or Not released, and a Language; they combine, act on every row at once and are remembered for your account.
- **Bulk actions on Activity, Wanted.** Tick titles on the Wanted pages, or Select all, then search, download now or stop following them together; Starboard asks first and names how many.
- **Discord support server link.** The footer of every page, About and updates, the help centre and the README now link to the Starboard Discord support server.
- **Fallback posters.** When an app has no small posters of its own, Coming up uses the picture the app gives, then TMDB's poster, each at a small size.
- **Restore a full backup on this server.** Each full backup in the folder has Restore beside it; nothing changes until both passwords are right and the whole file has been read, and Starboard makes a backup of how things are now first.
- **Each full backup is checked after it is made.** Starboard reads the new file back and the list says Checked; a backup that does not read back is not kept and is reported as failed.
- **Reelix's backups on another disk than its settings.** When the media folder is on another disk, you can choose where Reelix keeps its backups, with each disk named.
- **What was added, failed and upgraded across your apps.** Activity, History has a second page, Across apps, kept small and costing nothing at rest.
- **Report a bug with a guided GitHub issue form.** New issue on GitHub opens a form that asks what you did, what you expected and what happened, and links to the Discord support server.

## Changed

- **Pages load the design system's new components only where they are used.** The median compressed page fell from 148,865 to 132,649 bytes, 16.2 KB or 10.9%, because a page loads a part only when it uses it.
- **Search no longer repeats Added in a toast.** After Add in the legacy Search the slide-out already says it, so the toast is gone; screen readers still hear it.
- **Download only what you have the right to, on About.** The notice now covers every download app, torrents as well as Usenet, in the same words as the help footer.
- **Apps that are not responding are checked less often.** After 2 checks with no answer Starboard waits longer between checks, up to 5 minutes, and the first answer puts it back to every check.
- **The updater's backup is smaller.** Fetched posters and icons, the logs and the Library's lists are left out of the copy of the data folder made before each update.
- **Set-up code, and a heading for each page.** The one-time code is called the set-up code everywhere, and its page is called Create your password.
- **Reelix's backup settings follow the settings patterns.** How often Reelix makes a backup and how many it keeps are selects that apply at once.
- **A full backup is put back only once it has been read to its end.** A damaged or cut-off backup now leaves a new install as it was.

## Fixed

- **Install all updates.** The moving bar shows from the moment the panel says Installing updates and grows as each update ends.
- **The VPN card said No VPN on a server that uses one.** Starboard now reads a kept Gluetun's own health check, so the card says Connected or Not connected, or Not known when it cannot tell.
- **Restoring a full backup stopped with Permission denied.** The working copy of the backup is now readable by Starboard, so the set-up's Restore a backup can open it.
- **The footer check knew only some links.** The browser journey now expects the Discord support server link beside Help, so a page that loses it is found before a release.

## Security

- **Security scan.** Trivy (image and configuration), Gitleaks, Bandit, ShellCheck, Hadolint and ZAP signed out (58 passed) and signed in (112 passed) found nothing to fix.

## Your settings and the way back

Your settings stay as they are. To go back, run ./update.sh --to v0.26.0.
