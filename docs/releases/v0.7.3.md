# Starboard v0.7.3

Released 2 November 2026.

## Changed

- **App cards.** The reply time is on the right, so long versions such as 2.7.0.5723 have room. An unknown version shows nothing, and an app that does not answer shows N/A for its reply time.

## Fixed

- **Long versions.** A long version number no longer runs into the reply time; on a very narrow card it breaks after a dot.

## Your settings and the way back

No settings change. To go back, run ./update.sh --to v0.7.2.
