# Starboard v0.20.1

Released 17 November 2026.

## Fixed

- **Jellyfin 12 and plug-in libraries.** Adding a plug-in's libraries to Jellyfin and the poster check on the Library health page work again with Jellyfin 12, which turns away the older way of sending its key.
- **Release notes for 0.15.2.** Starboard's own notes for 0.15.2 now show the Added entry this changelog has, not a second wording of it.

## Security

- **Code and writing checks.** Once a week GitHub checks the code for likely bugs, the writing rules, misspellings and the safety of its workflows, and that the tests run as much of the code as before. The workflows' actions are pinned to exact versions and kept up to date.
- **The key check reads the whole history again.** The release check for keys and passwords read no history at all when run from a second working copy, so it passed without looking. It now reads all of it: it found only made-up keys in tests and one placeholder in the help.

## Your settings and the way back

Your settings stay as they are. To go back, run ./update.sh --to v0.20.0.
