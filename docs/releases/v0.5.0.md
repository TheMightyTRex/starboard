# Starboard v0.5.0

Released 2 November 2026.

## Added

- **Install apps.** A guide that sets up a media server in groups (Movies, TV, Music, Ebooks, Audiobooks, Comics and more): it writes a Compose file, shows it, and starts the apps when you give your password. It can point them at your media where it is. Help: [Install apps with Starboard](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/install-apps.md).
- **Storage charts.** System, Storage shows the pool as a bar and a ring by type (TV, films, books and more) with free space, each drive in the pool, space used over time with a forecast, and the biggest series and films. Help: [Check free space and what is using it](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/check-storage.md).
- **Search for new apps.** Manage apps finds apps on this computer and adds the ones you tick, with their API keys if Starboard has Docker access. Help: [Search for apps already on your server](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/search-for-new-apps.md).
- **Set-up guide.** Finds your apps, then asks about API keys, Jellyfin, download hours, alerts and how much Starboard does. Run it again from Settings, General.
- **Release notes.** Select the version in the footer to read what is new.
- **Upgrade guide.** After an upgrade with something to choose, a short guide shows what is new and asks only those questions.

## Your settings and the way back

Adds a record of the set-up guide and the last upgrade, and three Storage settings in Settings, Performance (sorting by type only when you ask, a daily record of used space, and page updates only when you press Check again). To go back, run ./update.sh --to v0.4.0.
