# Starboard v0.5.5

Released 2 November 2026.

## Added

- **System, Logs.** What Starboard did and every problem it met, newest first, with Download and Delete logs. Kept for 60 days by default (Settings, General). Help: [Read the log and report a problem](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/read-the-log.md#read-the-log).
- **Report a problem.** Detailed logging for 24 hours, then Copy the details and Open a new issue on GitHub. Passwords, API keys, addresses and names are removed before anything is written. Help: [Read the log and report a problem](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/read-the-log.md#report-a-problem).

## Changed

- **Docker's log.** Holds only start-up and problems, capped at 3 MB in the Compose files.

## Fixed

- **System, Overview.** The charts' history loads again (broken since 0.4.0).

## Your settings and the way back

Adds log settings: kept for 60 days, detailed logging off. To go back, run ./update.sh --to v0.5.4.
