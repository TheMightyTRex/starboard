# Starboard v0.40.0

Released 27 November 2026.

## Added

- **Starboard 0.40.0 is a clean break: update from 0.31.0 or later, and you cannot go back by the usual way.** The update stops before it changes anything if you have a version before 0.31.0, and says to update to 0.31.0 first. Before any other change it saves a backup of your settings, checks that it reads back, and says in plain words that you cannot go back to an older Starboard afterwards. Your settings move to the new layout once, and Starboard keeps every setting and every app it does not understand. To go back to a version before 0.40.0, run ./update.sh --to with that version and --restore with the name of the backup: this is the safe way, and settings you changed since are lost. Without --restore, the updater warns you that your settings may not match, saves a fresh backup and goes on.
- **Plug-ins can hold heavy jobs on battery.** A plug-in with the new power:hold permission, such as UPS and power, asks Starboard to hold its background jobs, scheduled backups, other plug-ins' scheduled jobs and downloads while the computer runs on battery.
- **Speed limits for qBittorrent and NZBGet.** Settings, Downloads, Speed limits sets how fast each may download, and how fast qBittorrent may upload, with the switch for qBittorrent's alternative limits.
- **Scan Audiobookshelf from Starboard.** Settings, Audiobookshelf has a Scan Audiobookshelf now button, which asks each of its libraries to scan its folders and says which it asked.
- **Backups on System.** System, Overview has a Backups panel: the newest full backup and that it was read back, whether full backups by themselves are set up or late, and whether the other places hold the newest one.
- **Each backup place has its own rule for how often it gets a copy.** Beside each place under Where backups go, Copy is Every backup, At most once a week or At most once a month, and applies at once.
- **Set up full backups by themselves, step by step.** A server that never kept the backup password made no full backup on its own, and nothing said so unless a schedule was chosen.
- **Phone apps for Kavita.** Manage apps and the Kavita plug-in's page now name KOReader and Kover for Android, and Sutra and Komic for iPhone and iPad, with what each needs: your Kavita address and Auth key, iOS 17 for Sutra, and https away from home for Komic.
- **Jellyfin, Plex and Emby compared.** Settings, Plug-ins, Catalogue, Media servers has How much each uses: four charts, each with a table, for memory at rest, processor at rest, time to start and size of the image.
- **Run your media server from Starboard.** The media server tab has Administration: read the libraries and scan one or all, refresh everything (after a question), read and run the scheduled tasks, read the activity, and read the server's logs, for Jellyfin, Emby and Plex where the server allows it.
- **Play and Watched for Plex and Emby.** Library now shows Play and Watched for the media server in use, whichever it is: Plex and Emby links open the item in the server's own web app.
- **Make, pause and delete accounts in your apps from People.** For Jellyfin and Audiobookshelf, More beside an account makes the account, checks it, pauses it, resumes it or deletes it, and gives a child limits (an age rating in Jellyfin, chosen libraries and no downloads or deleting).
- **Will other people use your apps?.** The set-up, in the browser and in the terminal, now asks it with the same words and recommends single sign-on when the answer is yes.
- **A plug-in that uses a feature that is going says so, and Starboard counts who still calls a retiring route.** The plug-in's page and the plug-in tester show one plain sentence with the day it stops.
- **Starboard tells you when a proxy is not listed.** If a request says it was forwarded but comes from an address in neither STARBOARD_PROXY_ADDRESSES nor this computer, Starboard writes one warning in its log for that address, because every visitor behind it would count as one.
- **Checks that catch a break to the public API, and a weekly compatibility run.** A check with oasdiff fails a change that would break an outside tool, with the last release as the baseline.
- **A line on every plug-in saying what it replaces or adds to, and an icon for its tab.** Each plug-in in the shipped catalogue now has a line such as "Adds to Jellyfin: stops it converting files as they play", shown on the Catalogue card, in the warning before install, on the plug-in's page and in Manage.
- **People.** Settings, People lists the people who use your apps, and Starboard makes a long, unique password for each person in each app, shown only after you enter your Starboard password.
- **Find all wanted.** Every Library tab and every Wanted page has Find all wanted.
- **Compatibility check for the API.** A new check fails a change that takes away or tightens a route, permission, manifest field, card, event or key scope without the deprecation steps, and runs 74 older plug-in manifests against this Starboard.
- **Plug-in updates found at once, in one list.** Check now reads every plug-in catalogue again, says when it last did and why one did not answer, and waits 30 seconds between presses.
- **Plug-ins can name the API they were tested with and the optional parts they need.** Plug-in API 1.21 adds starboard_tested and capabilities, GET /api/v1/ lists the capabilities, the catalogue skips a version that needs one this Starboard lacks, and the plug-in tester checks the version range a plug-in names.
- **The API says when a feature is going, and answers 410 when it is gone.** GET /api/v1/ lists the features that are going (none yet), and a route that is going carries Deprecation and Sunset headers.
- **A page that says what we promise plug-in developers.** It covers what never breaks inside version 1, how a feature is retired, how a plug-in says what it needs and what people are shown when one stops.
- **Carry your libraries, people and watched state to another media server.** Switch with help now reads both servers first, lists each library and person it would carry across, and does nothing until you confirm.
- **Jellyfin, Plex and Emby side by side.** Plex or Emby from Install apps, or added in Manage apps, now shows as installed and not in use, ready to check and choose with no extra step in the catalogue.
- **Sign in to Plex with a link code.** Manage apps has Sign in with Plex, which shows a code to enter at plex.tv/link, or you can still paste the token.
- **A first sign-in for app plug-ins.** A plug-in can now set its app's first password, and the plug-in's page shows it once after you enter your Starboard password.
- **A wizard for switching media server.** The media server tab in Settings, Apps has Switch with help, which says what moves, what cannot and what keeps working before anything changes.
- **Plex and Emby as kinds of app.** Manage apps, Add an app now lists Plex and Emby, each with its own form and connection test.
- **Phone apps for Calibre-Web.** Starboard now names and links the apps for reading Calibre-Web books on a phone: KOReader and Calibre-Web-Companion for Android, and Readest for iPhone and iPad.
- **Several places for backups.** Settings, General, Backup/Logs has Where backups go, which copies each backup to a folder, a network share or a cloud service.
- **A custom card for any service's JSON.** System, Apps, Other services has Custom cards, which show the fields you choose from any service's JSON on a dashboard card.
- **A link to the plug-in store.** The README and the help topics The plug-in collection and Add a plug-in now link to the Stallboard plug-in store.
- **Plug-ins show the system they need.** A tag such as Jellyfin only, Plex or Emby, or Needs Reelix now shows on each plug-in that needs one.
- **One place for the media server.** Starboard can now ask any media server the same nine questions, with Jellyfin as the first and the default.
- **Jellyfin as a built-in plug-in.** Jellyfin now has its own page in Settings, Plug-ins, and its address, key and settings stay where they were.
- **Choose your media server.** Settings, Apps now lets you check your media server, choose another one and go back to the old one within 24 hours.
- **Emby and Plex as media servers.** Both are now built-in plug-ins that the dashboard can show, read only for now.

## Changed

- **Design system copies brought up to date.** The shared styles and scripts match the design system again.
- **Logos of services, used only as the companies allow.** Google Drive and OneDrive show the plain cloud icon and their full name, not a redrawn logo.
- **Add the rest on a collection or series.** The button that adds what a collection, book series or audiobook series lists and Reelix does not have is now Add the rest (n), and its question says Add n films to Reelix.
- **Radio's Find all wanted says how many shows have wanted episodes.** The button on the Radio tab now carries a count, such as Find all wanted (3 shows), and is inactive when nothing is wanted.
- **Select several works on every Library tab.** Music, Books, Audiobooks and Radio now have Select several with Follow and Stop following (and Delete, except on Radio), up to 100 at a time.
- **One verb for searching in the Library.** Get it, Get the missing episodes, Get the n missing and Search are now Find it, Find wanted episodes with a count, Find wanted albums and Find n wanted episodes, and a radio show has Find wanted episodes too.
- **One set of words for what you have and want in the Library.** Every tab now says In library, Partly in library, Wanted, Downloading, Below quality, Not followed, Not added or Not released, where it said Not in library, Episodes not in library, Tracks not in library, Not wanted, Not requested and more.
- **General has seven tabs.** Discover rows are now sections of Lists, and Pictures is a section of Performance, each with a list of links at the top of the page.
- **Three tab icons are easier to tell apart.** In Settings, Pictures has a picture icon, Tdarr (in Apps) has a chip, and Updates has an upward arrow, so no two tabs in a row look the same when only icons show.
- **Every row of tabs condenses like the plug-in tabs.** Where the names do not fit, a row under the header now shows icons only, with each tab 44 pixels wide and the tab you are on in full; the arrow keys, Home and End move along the row, and a fade shows when it scrolls.
- **One way to copy to the clipboard.** Copying log lines and the log report now say when they could not copy, and the page shares the design system's copy code.
- **One way to ask for your Starboard password.** Every box that asks for it says "Your Starboard password", and an empty one says "Enter your Starboard password", in Backups, Reelix, Pool, Downloads, Jellyfin, Logs, Security, Clean-up and sign-in settings.
- **One way to write a count and a time.** System, Storage, Disks, Pool, Monitor, Downloads, Library and On demand history share one count in words and one clock, so a count over a thousand has its comma on every page.
- **One look for a short wait.** Loading lines in help, release notes, set-up steps, Discover, radio settings and a few more now show the waiting ring with words that say what is loading, in place of a plain "Loading…".
- **One look for a notice.** A message in the page (an error, a warning, a note) is drawn by one function, so an error notice in Downloads, Search, Search the sites and On demand history now has the same circle-with-exclamation icon as everywhere else.
- **Lighter pages again.** Styles for parts of the design system that no page uses (cover cards, the logo editor, the decision tree and more) are no longer sent with every page, so each page's style sheet is about 14 KB smaller.
- **Plug-in catalogues are read every 6 hours.** Starboard reads them again with its look at GitHub, only while a page is open and only when you have added a plug-in, instead of once a day.
- **A notice with buttons reads properly on a phone.** Any notice with buttons or a link keeps its words readable at 375 pixels wide: what follows the words goes on its own row under them.
- **Each plug-in's tab has its own icon.** Settings, Plug-ins now draws a different line icon on each plug-in's tab, and where the tabs show icons only, such as on a phone, the tab you are on and the tab with focus also show their name.
- **Starboard no longer reads Plex's token.** Search for new apps does not look inside the Plex container for the token any more.
- **Display opens as a slide-out on Sign in and Set up too.** The sign-in page had its own copy of Display as a dialog; it now uses the same template as every other page.
- **Error lines under fields use the shared `field-error` class.** Three messages (app details, Reelix system and plug-ins) had a class name with no style.
- **The shared styles now define the names Starboard already used.** --radius-sm, --radius-md, --font-mono, --color-success-text, --color-danger-text, stack-3, stack-5, input--narrow, select--compact, field__error and btn--secondary had no style, so a few boxes in Bring in, Backup and restore and the dashboard editor gained their intended spacing and width.
- **One name for asking again: Check now.** Every Check again button and line of help now says Check now, as plug-ins do, and the Updates button says Check now before and after the first check (owner, 26 November 2026).
- **One Backup/Logs tab.** Settings, General has Backup/Logs, which holds backups, restoring, logs and Send feedback, and the old addresses still open it.
- **Shorter names in General.** The first tab is now General, and the others are Appearance, Lists, Discover, Hours, Alerts, Performance, Pictures and Backup/Logs, so every name fits at 1280 pixels wide.
- **One tab for your media server.** Settings, Apps has one tab named for the media server in use, so the separate Media server tab and plug-in tab are gone.
- **Alerts and Performance are part of General.** Settings, General has new Alerts, Performance and Pictures tabs, and the old addresses still open the right page.
- **Lighter pages and quicker tests.** Page scripts and style sheets are now built without comments and blank lines, so a first visit sends about 38 KB less.
- **Two small savings.** The dashboard now asks for the settings once instead of twice.
- **Plain English pilot.** The README and the help topics Add an app and How lean Starboard is now use shorter sentences and the active voice.

## Removed

- **Old settings anchors.** A saved link such as settings-general.html#gn-logs now opens the page at the top, not at the part that moved to another page.
- **Settings steps for versions before 0.31.0.** The update to 0.40.0 refuses to start from a version before 0.31.0, so the old steps that brought a settings file from before 0.31.0 up to date are gone.
- **Compose rewrite for plug-ins from before 0.17.0.** Starboard no longer rewrites a plug-in's Compose file that mounts its settings, key and Jellyfin files one by one.
- **Design system parts no page loads.** 23 style and script files for parts of the design system that no page of Starboard loads (combobox, popover, alerts, pagination, schedule, command palette and the styles-only parts) are gone from the web folder, about 89 KB. No page changes, because none loaded them. web/parts-used.json lists the six parts that pages load, and the design system's sync writes only those.
- **Unused code.** Eight unused names and one unused option are gone from Starboard's code, and one condition that could never be true is gone from the tool that builds the AI-readable help.
- **Old release note files and two unused documents.** The notes files of 57 releases from 0.5.0 to 0.28.0, an unused picture of all the screenshots and the design record for building plug-ins in isolation are gone from the repository.
- **Four hand-run test scripts.** The scripts that tried Bring in on shares, copies off this computer, connecting a cloud service and a full restore by hand, on made-up data, are gone from the tools folder.

## Fixed

- **The TV, Music and Radio pages no longer scroll sideways at large text.** A card now shrinks to its column and wraps its status and details, so a wide chip cannot push the page wider than the window.
- **Creating your first password works again.** The first password page never wired its form from version 0.28.0, so Create did a plain page reload and saved nothing.
- **Two labels now hold the words you see.** Voice control users say what they read.
- **The hover outline of a topic tab meets the line under the tabs.** The outline stopped 3px above the line under the menu of topics on a settings page.
- **Field errors say "Error:" to a screen reader.** An error under a field, such as an empty password, now starts with the hidden word Error: , as the design system asks, so it is not read as a plain sentence.
- **An artist's Get it searches for every wanted album, up to 100.** It used to stop at 20 without saying so.
- **An even row of controls on a Library item page.** On a radio show, the Following list now sits in the same frame and height as the buttons beside it, and every control on a film, series, artist, book, audiobook or radio show page is one height and wraps on a phone.
- **A full backup that was not made is now reported.** A scheduled backup with no saved backup password used to say it had run.

## Security

- **A running plug-in that needs a part Starboard lacks is stopped.** A plug-in whose capabilities.needs names something this Starboard does not have now shows Needs an update with the reason, like one whose API range does not fit.
- **A downloaded settings file no longer holds a plug-in's keys or secrets.** Plug-in settings that are secrets, and a plug-in's own key, are left out of the file.
- **Requests with a Transfer-Encoding are refused.** Starboard now answers 400 and closes the connection, so a proxy in front of it cannot hide a second request inside a body.
- **One guarded way to fetch a plug-in's manifest, catalogue and logo.** Starboard now checks every redirect and the address it connects to, so an address that redirects, or changes its answer, cannot reach your home network's private services or a cloud metadata address.
- **A plug-in Starboard cannot run is stopped, and says why.** When Starboard starts, a plug-in whose API range leaves out this Starboard, or that uses something that is gone, is stopped (not removed) and shows Needs an update with the reason.
- **A plug-in's own key changes each time it starts, and ends when it is not used.** The key is new at every start and update, ends 30 days after its last use, and works on the plug-in's socket only when the plug-in cannot reach Starboard's port anyway.

## Your settings and the way back

Your settings move to the new layout once, after a backup that Starboard saves first in the backups folder. You cannot go back to an older Starboard by running it on the new settings. To go back, run ./update.sh --to v0.31.1 --restore backups/NAME, with the name of that backup. Settings you change after the update are lost when you do. Without --restore, update.sh warns you that your settings may not match, saves a fresh backup and goes on. The plug-in API stays 1.x and every old page address still redirects.
