# Starboard v0.6.0

Released 2 November 2026.

## Added

- **Listening progress.** Settings, Audiobookshelf copies where everyone is in each audiobook, and what they finished, from Plex, Jellyfin, Emby or another Audiobookshelf. Progress people already have is never changed, and books not found are listed.

## Changed

- **Audiobookshelf.** Is an app type of its own, with its version and an optional admin API key. Apps named Audiobookshelf move to it by themselves.
- **Install apps.** Listening progress is no longer marked coming soon.

## Your settings and the way back

Adds a switch to keep applying listening progress (off; on in the Everything preset), and gives apps named Audiobookshelf their own type. To go back, run ./update.sh --to v0.5.6, which keeps the app as an Other app.
