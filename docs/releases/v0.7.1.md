# Starboard v0.7.1

Released 2 November 2026.

## Changed

- **Updates.** Each app has its logo beside its name. Installed and Latest are left-aligned, every category's table has the same column widths so the columns line up, and each row's cells sit on the middle of the row. Help: [Update your apps](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/update-your-apps.md).

## Fixed

- **Long API keys.** Keys were cut to 200 characters when saved, so Audiobookshelf, whose keys are longer, refused its key. If Audiobookshelf says the key is wrong, paste it again in Manage apps. Help: [Find an app's API key](https://github.com/TheMightyTRex/starboard/blob/main/docs/help/topics/find-an-api-key.md).
- **Log.** A connection that stayed idle until it timed out no longer writes an error to Docker's log.

## Your settings and the way back

No settings change. To go back, run ./update.sh --to v0.7.0.
