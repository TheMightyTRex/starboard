# Approve or decline requests

When people ask for a film or series in Seerr, Jellyseerr or Overseerr, Starboard lists their requests on the
Downloads page. You can approve or decline each one there, without opening Seerr.

## Before you begin

- Seerr, Jellyseerr or Overseerr is in Starboard with its API key. When you add it, choose **Seerr, Jellyseerr
  or Overseerr** as the **Kind of app**. Read [Add an app](add-an-app.md).
- The API key is in Seerr under **Settings**, then **General**. Read
  [Find an app's API key](find-an-api-key.md).

## Steps

1. Go to **Downloads**, then **Requests**. The page says how many requests are waiting for approval.
2. Find the request. Each one shows the title, the year, the kind, who asked for it and when.
3. Select **Approve** to accept it. Starboard shows **Approved** and the title. Seerr then handles it as if
   you had approved it in Seerr itself.
4. Or select **Decline** to turn it down. Starboard asks you to confirm, because the person who asked sees
   that it was declined.
5. Select **Decline** again in the message to confirm.

## Things to note

- The page shows **Waiting for approval** at first. Select **All recent** to see the newest requests of every
  kind, with their state.
- **Check again** asks Seerr for the latest requests straight away.
- A declined request cannot be undone from Starboard. To change your mind, open Seerr itself: select
  **Open** and the app's name, such as **Open Seerr**. It opens in a new tab.
- When the download for an approved request starts, it appears in **Downloads**, then **Queue**.

## If it does not work

- **Add Seerr to see requests here:** Starboard has no Seerr app with an API key. Edit the app in **Settings**,
  then **Manage apps**, set its **Kind of app** and paste the API key.
- **Could not ask Seerr** and a message: Seerr did not answer. Check it is running. Read
  [An app shows as not responding](app-not-responding.md).
- **Not done** and a message: Seerr refused the action. Open Seerr to check the request.
