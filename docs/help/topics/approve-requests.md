# Approve or decline requests

When people ask for a film or series, Starboard lists their requests in **Activity**, then **Requests**. You can
approve or decline each one there. Reported problems with a film or series are in **Issues** on the same menu.

## Before you begin

- Reelix, or Seerr, Jellyseerr or Overseerr, is in Starboard with its API key. Read [Add an app](add-an-app.md)
  and [Find an app's API key](find-an-api-key.md#where-each-app-keeps-its-key).
- When you have Seerr, Jellyseerr or Overseerr, Starboard shows its requests. Without one, it shows Reelix's own
  requests.

## Steps

### Approve or decline a request

1. Go to **Activity**, then **Requests**, then **Requests**. The page says how many requests are waiting for
   approval.
2. Find the request. Each one shows the title, the year, the kind, who asked for it and when.
3. Select **Approve** to accept it. Starboard confirms with **Approved** and the title.
4. Or select **Decline** to turn it down. Starboard asks you to confirm, because the person who asked sees that
   it was declined.
5. With Reelix's requests, you can enter a reason in **Why (optional)**. The person sees it with the answer.
6. Select **Decline** again to confirm.

A Reelix request that failed shows **Try again**. Select it to ask Reelix to try again.

### Answer a reported issue

People can report a problem with a film or series in Reelix. Starboard shows those reports as issues.

1. Go to **Activity**, then **Requests**, then **Issues**. The page shows **Open** issues first. Select
   **Resolved** or **All** to show the others.
2. Select **Comment** or **Comments** under an issue to read the thread.
3. Optional: enter your answer in the box, then select **Add comment**.
4. Select **Resolve** when it is sorted. To open it again, select **Reopen**.

## Things to note

- Requests show **Waiting for approval** at first. Select **All recent** to show the newest requests of every
  kind, with their state.
- **Check again** asks for the latest requests straight away.
- A declined request cannot be undone from Starboard. To change your mind, select **Open** and the app's name,
  such as **Open Seerr**. It opens in a new tab.
- When the download for an approved request starts, it appears in **Activity**, then **Downloads**, then
  **Queue**. Read [Pause, resume and remove downloads](manage-downloads.md).

## If it does not work

- **Add Reelix or Seerr to see requests here:** Starboard has no Reelix or Seerr app with an API key. Add one
  in **Settings**, then **Apps**, then **Manage apps**. Read [Change or remove an app](change-or-remove-an-app.md#change-an-apps-details).
- **Could not ask Seerr** and a message: the app did not answer. Check it is running. Read
  [An app shows as not responding](app-not-responding.md).
- **Not done** and a message: the app refused the action. Open the app to check the request.
