# Sign out everywhere

Sign out every browser and phone that is signed in to Starboard, including the one you are using. Use it
after you lose a phone, or when you signed in on someone else's computer.

## Steps

1. Go to **Settings**, then **Security**.
2. Activate **Advanced settings**, if it is not active already.
3. Under **Sessions**, find **Sign out**, then select **Sign out everywhere**.
4. Starboard asks **Sign out everywhere?** In **Your Starboard password**, enter the password.
5. Select **Sign out everywhere** to confirm.

Starboard signs everyone out and shows the sign-in page. Everyone needs the password to sign in again.

## Things to note

- Starboard asks for the password so that someone using a browser you left signed in cannot sign everyone out.
- To sign out only the browser you are using, select **Sign out** instead. It is in the header of every
  Settings page, and in the phone menu.
- Sign-ins survive a restart of Starboard or the server, so a restart does not sign anyone out.
- If you think someone else knows the password, [change your password](change-your-password.md) instead.
  That also signs out everyone else.
- API keys are not signed out. To stop one, read
  [Make an API key and use Starboard's API](use-starboards-api.md#revoke-a-key).
- In the same **Sessions** section, **Remember me keeps people signed in for** sets how many days a sign-in
  with **Remember me on this device** lasts, from 1 to 90. Enter a number and select **Save**. Without it,
  people are signed out when they close the browser, or after a day.

## If it does not work

- **"That password is not right":** check Caps Lock and enter it again. Nobody has been signed out.
- **"Too many attempts. Wait 15 minutes and try again":** after five wrong passwords, Starboard waits 15
  minutes before it accepts another try from the same device.
