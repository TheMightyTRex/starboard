# Change or remove an app

Change an app's address, API key or card, hide it from the dashboard, move it in the list, or remove it from
Starboard. Nothing you do here changes the app itself.

## Before you begin

- The app is already in Starboard. If it is not, read [Add an app](add-an-app.md).

## Steps

### Change an app's details

1. Go to **Settings**, then **Apps**, then **Manage apps**.
2. Select **Edit** for the app, or select its name. A side panel opens, such as **Edit Sonarr**.
3. Change what you need, such as **Address Starboard uses** or **API key**. Leave **API key** empty to keep the
   saved key.
4. Select **Test connection** to check that the app still answers.
5. Select **Save app**. For Sonarr, Radarr, Lidarr and Readarr the button is **Save and continue**: check the
   **Adding options**, then select **Save adding options**.

### Hide an app without removing it

1. In **Manage apps**, select **More actions** (three dots) for the app.
2. Select **Hide from the dashboard**. The app stays in **Manage apps**, marked hidden from the dashboard.
3. To bring it back, open the same menu and select **Show on the dashboard**.

### Change the order of apps

1. In **Manage apps**, select **More actions** for the app.
2. Select **Move up** or **Move down**. The app moves one place within its category.

### Remove an app

1. In **Manage apps**, select **More actions** for the app, then **Remove**. The app's **Edit** panel also
   has **Remove**.
2. Starboard asks you to confirm. Select **Remove** and the app's name, such as **Remove Sonarr**.

## Things to note

- Removing an app takes it off the dashboard and, for Sonarr, Radarr, Lidarr and Readarr, off the Search page.
  The app, its files and its settings stay as they are. You can add it again at any time.
- An icon beside each app's name in **Manage apps** shows its state: **Connected**, **Cannot connect** or
  **Hidden from the dashboard**. For a background service, it shows **Running** or **Not running**.
- To move an app to another category, change **Category** in its **Edit** panel. Read
  [Organise apps into categories](organise-categories.md).
