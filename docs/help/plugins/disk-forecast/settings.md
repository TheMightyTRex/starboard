# Disk forecast: Settings
<!-- Mirrored from the starboard-plugins repository by tools/sync-plugin-help.py: change it there. -->

Disk forecast has no settings of its own, and no buttons. It reads how full each disk is from Starboard.

## Things to note

- It measures once an hour and keeps one reading a day for each disk, for the last 35 days, in its own folder.
- A forecast needs readings from two different days. On the first day, every disk says "not growing".
- It forecasts from the oldest day it kept, so a big download or a big clean-up changes the forecast for up to 35 days.
- It only reads. It never changes or deletes anything on your disks.
