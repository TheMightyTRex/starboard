# Calibre library maker: Dashboard card
<!-- Mirrored from the starboard-plugins repository by tools/sync-plugin-help.py: change it there. -->

Calibre library maker has no dashboard card. A card would ask it for its state, which would wake it and keep it running. It shows its progress on its own page instead.

## Where to check on it

- Go to **Settings**, then **Plug-ins**, then **Calibre library maker**. The page shows how far a run has got.
