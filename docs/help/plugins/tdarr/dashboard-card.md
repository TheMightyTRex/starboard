# Tdarr: Dashboard card
<!-- Mirrored from the starboard-plugins repository by tools/sync-plugin-help.py: change it there. -->

Tdarr has no dashboard card. It is a whole app with its own page on your home network. What it has converted and the space saved so far are under **Files Tdarr knows**, in the **Settings** section of its tab.

## Open Tdarr

- On its tab, in **Settings**, then **Plug-ins**, then **Tdarr**, select **Open Tdarr** under **Its web page**.
- In the list in **Settings**, then **Plug-ins**, select **Open** beside Tdarr. It is there while it is active.

Its page opens in a new tab.
