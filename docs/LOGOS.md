# Logos of services

Starboard shows a logo beside a service's full name on Settings, General, Backup/Logs, only to say which service a
place is. The logos are a single colour in `web/icons/services.svg`, drawn by [Simple Icons](https://simpleicons.org/)
(CC0 1.0 for the artwork). The artwork licence does not give the right to use a trademark: each mark stays its owner's.

| Service | Shown | Why |
|---|---|---|
| Google Drive | Plain cloud icon | Google's rules allow its own logo, resized and with no other change. A one-colour redraw is a change. Add the official logo here only when it is taken from Google's branding page. |
| OneDrive | Plain cloud icon | Microsoft allows its logos only with an express licence. |
| Dropbox, Backblaze B2, Amazon S3, Nextcloud | One-colour mark | To identify the service. Not checked against each company's own brand page: check before a release. |
| SFTP, SMB, NFS, folders | Starboard's own icons | No brand. |

Rules for every logo: the full name always sits beside it, it is never the app's own icon, it is not changed in colour
or shape beyond the single colour, and the page loads it only on Backup/Logs.
