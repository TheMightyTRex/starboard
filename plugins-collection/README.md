# Starboard's plug-in collection

The plug-ins listed in the help centre's [plug-in collection](../docs/help/basics/plugin-collection.md), each in its
own folder, with a zip of each folder beside it.

| Plug-in | Install address | Download |
|---|---|---|
| Styles | `https://raw.githubusercontent.com/TheMightyTRex/starboard/main/plugins-collection/styles/starboard-plugin.json` | [styles.zip](styles.zip) |

To add one, copy its install address into **Settings**, **Plug-ins**, **Add a plug-in**. Each one has passed
Starboard's plug-in tester, accessibility included.
