Backup and restore

Two kinds of copy: Settings only, a small file, and Full without media, which rebuilds the server on a new install.

When backups are made

Starboard can make the backups by itself at 03:00, when the server is quiet, and keep only the newest few.

Full without media

Starboard, its plug-ins and every app's settings and database, encrypted with a password you choose. Restore it on this server to go back to an earlier day, or on a new install to get the same server back. Nothing that can be downloaded again goes in.

Where backups go

After each full backup, Starboard copies it to every place you activate and keeps the newest few in each, so a failed disk, a theft or a fire does not take every copy. A backup counts as safe only when each place has read it back. Nothing runs between copies.

Settings only

Starboard's settings, your apps and their API keys, categories, plug-in settings and logo choices, in one small file. Not your password, and not the apps' own settings.

Copies Starboard saved

Made before every restore and before an update changes the settings.

    The whole server, by its own job

    Every app's settings and databases, system settings and the package list. Not your media.
